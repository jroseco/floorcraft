# Floorcraft: Dance Finder

Ballroom socials, club nights, classes, movement sessions and competitions near any zip code, town or county.

- `index.html` — the app (no build step; plain HTML/CSS/JS)
- `data/events.json`, `data/places.json` — the listings (updated daily)
- `zips.json` — US zip code → location lookup
- Nearby studios anywhere in the US are looked up live from OpenStreetMap.

Hosted free with GitHub Pages.
